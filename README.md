# AirDribbleTrainer
A Rocket League plugin that helps players improve their aerial ball control. It works by teleporting the ball and car to the opposite side of the arena when it gets too close to the walls, floor, or ceiling, creating a boundless airspace to practice.

Demo video: ['Air Dribble Trainer Bakkesmod Plugin' by 4J4_rl](https://www.youtube.com/watch?v=ilkqJ74NAGA&t=5s)

Look in this plugin's tab in the bakkesmod plugins tab for settings, and apply the keybinds that start with AIRDRIBBLETRAINER::* in the keybinds tab to activate/deactivate it. It can additionally be deactivated by resetting freeplay.
